# architectural-room-planner

A practical layout tool where users can design a floor plan and place furniture.

## Features

- *Primitive Geometries:* Uses basic drawing techniques such as lines, rectangles, and circles to establish a 2D top-down floor plan.

- *3D Projections:* Allows users to toggle into a 3D perspective or projection view to see the room modeled in 3D space.

- *Transformations & Input:* Utilize mouse input to drag and drop items, and keyboard inputs to apply 2D/3D scaling and rotation to resize and orient furniture.
